# Interlake Construction website — instructions for Claude

Any Interlake team member may ask for changes in chat. Make the change, publish, and reply with the link.

## Layout
- `src/build.py` — ALL page content, header/footer, SEO (titles, descriptions, JSON-LD), business info (BIZ), service-area cities (REGIONS), testimonials. Edit content here.
- `docs/` — the published site (GitHub Pages serves this folder). Regenerated by the build; don't hand-edit HTML pages.
- `docs/css/styles.css`, `docs/js/main.js` — edit directly.
- `docs/img/` — images. Each photo has `name-800.webp` and `name-1600.webp`.

## Publish a change
1. Edit `src/build.py` (and/or css/js).
2. `python3 src/build.py`
3. Commit and push to `main`. GitHub Pages updates in about a minute.
4. Tell the person what changed and give the page link.

## Adding a photo
Convert to WebP at 800 and 1600 px wide (Pillow, quality ~78, apply EXIF rotation), save as `docs/img/<descriptive-name>-800.webp` / `-1600.webp`, then reference it in build.py via `pic("<descriptive-name>", "alt text")`. Use descriptive, keyword-friendly file names and alt text.
